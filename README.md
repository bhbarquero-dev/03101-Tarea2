# 03101 - Tarea 2: To-Do List con gestión de estado

Aplicación web de administración de tareas personales (To-Do List) con operaciones CRUD asíncronas mediante AJAX.

**Curso:** 03101 - Programación avanzada en web (UNED), III Cuatrimestre 2026
**Estudiante:** Bernal

## Tecnologías
- ASP.NET MVC 5 (.NET Framework 4.8.1)
- JavaScript, jQuery y AJAX
- Gestión de estado: Session (servidor) y/o LocalStorage (cliente)

## Funcionalidades (historias de usuario)
1. Crear una tarea (título y descripción)
2. Marcar una tarea como completada / pendiente
3. Editar una tarea existente
4. Eliminar una tarea
5. Filtrar por estado (todas, pendientes, completadas)

Todas las operaciones se ejecutan sin recargar la página.

## Cómo ejecutar
1. Abrir `03101-Tarea2.slnx` en Visual Studio.
2. Restaurar paquetes NuGet.
3. Ejecutar con F5 (IIS Express).
